# 达·芬奇名画地图

参考《中国名碑名刻数字博物馆》的筛选、地图与列表交互，呈现本次对话涉及的名画介绍与收藏分布。

## 使用

```sh
python3 -m http.server 8775 --directory dist
```

浏览器打开 http://localhost:8775 。需要通过 HTTP 服务运行；直接双击 HTML 会受到浏览器本地文件读取限制。

- 地图／图录切换，按归属、国家、主题筛选，支持搜索。
- 地图聚合相邻收藏机构，点击展开作品或放大区域；世界视图包含华盛顿。
- 详情包含原作图像、创作年代、媒介、介绍、观看提示、归属说明与来源链接。
- 详情支持图片放大、上一件／下一件、键盘左右键和本地收藏。
- 支持手机布局、图录下载和作品链接（例如 `#work=mona`）。

## 收录口径

共21件：16件馆方署名绘画、2件合作作品、2件归属争议作品、1件纸本画稿；20件有已知收藏机构，分布于12个机构、8个国家。这个数字不是达·芬奇全部亲笔作品的学界定论。

《救世主》的确切现址未可靠确认，不设置地图坐标；《丽塔圣母》明确列为归属争议。《岩间圣母》包含巴黎与伦敦两个版本。地图表达收藏归属，不能证明实时在馆或开放展出。

## 文件与来源

- `dist/data.json`：作品、机构坐标与每件来源。坐标为机构近似位置。
- `dist/assets/images.json`：图像原始来源、维基共享资源文件页与本地路径。
- `dist/app.js`：交互与筛选。
- `dist/style.css`：桌面、手机布局。
- 地图：Leaflet 1.9.4（BSD-2-Clause，脚本保留版权标记），Natural Earth 数据的 GeoJSON 版本（https://github.com/johan/world.geo.json）。不依赖在线地图瓦片。
- 木板厅照片：Castello Sforzesco，CC BY-SA 4.0；来源与许可在作品详情中标明。照片以缩略图尺寸下载并缩放展示。
- 其余古典绘画复制图的来源与许可详见各图像文件页。
