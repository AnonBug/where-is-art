# 吴道子两幅传名画卷内容核验

核验日期：2026-11-02。范围限于《送子天王图》和《八十七神仙卷》；《道子墨宝》保留在前期研究资料中，本次不接入网站。

## 作品和馆藏

|作品|收藏机构|归属处理|下载像素|原件大小|
|---|---|---|---|---|
|送子天王图|大阪市立美术馆，日本大阪|传吴道子；后世托名摹本或再摹本，具体时代未定|29,312 × 3,000|19,998,638 字节|
|八十七神仙卷|徐悲鸿纪念馆，中国北京|传吴道子；央美图录列佚名，作者与年代有争议|25,902 × 2,800|17,394,493 字节|

《送子天王图》的馆藏和摹本判断依据[台北故宫2021年大阪借展说明](https://theme.npm.edu.tw/exh110/HiddenGems/ch/page-2.html)。借展不改变收藏机构记录。

《八十七神仙卷》的材质、佚名归属和馆藏依据[央美2018年展览图录](https://www.cafa.com.cn/cn/special_topics/details/5210049)。[李凇论文](https://www.cafa.com.cn/cn/research/details/8310082)讨论其作者和年代，提出北宋初期观点；此为研究观点，不作为学界一致结论，也不据此把画卷定为吴道子原作的摹本。两件均不计入确认吴道子亲笔。

画家年代采用“约686—约760（生卒不详）”，依据[巫鸿2022年研究](https://knowledge.uchicago.edu/record/5048/files/Unearthing-Wu-Daozi.pdf)，保留约年。生平与证据见 `content/wu-daozi-sources.json`。网站按历史传名把两卷关联至唐代画家，不表示现存画卷确定绘于唐代。

## 图像版本与复现

原件是 Wikimedia Commons 文件页所供的完整画幅；不含全部装裱与题跋，不宣称馆方最高分辨率。两页均标注 Public domain；具体文件页、许可栏目、下载地址、下载字节数与 SHA-256 记录于 `content/wu-daozi-sources.json`。馆藏文献与图像来源分开记录。

缩略图以局部构图裁成320像素方图，仅供导航；1280像素长边预览与高清DZI保留完整原图比例。DZI保持原始像素尺寸，使用512像素瓦片、1像素重叠，JPEG质量86、4:4:4采样；不通过放大低清原图制造细节。原始下载JPEG不重新编码覆盖。

两幅新增922张瓦片，网页资源总计 **68.03 MB**（含缩略图、预览、DZI描述文件及全部层级瓦片）。逐文件哈希在 `content/wu-daozi-media-manifest.json`；前端目录只合并显示与加载所需字段。

运行 `npm run media:wu-daozi` 可从本地缓存重建，缓存缺失时按已记录URL下载，哈希不符即停止。运行 `npm run content:build` 合并目录。`npm run media:check` 验证源信息对应关系、交付文件哈希、完整解码、全部层级的瓦片数量及边缘像素尺寸，不要求CI持有原件。

## 地图

两馆点位沿用前期已核实的 WGS84 机构坐标：大阪 `[135.510523, 34.650096]`、北京 `[116.3653196, 39.9436848]`。OpenStreetMap 对象链接与 ODbL 署名保留于各馆 `coordinateNote`。地图表示收藏机构，不表示库房、实时作品位置或当前展出。

## 验证结果

`npm test`：12个测试文件、70项测试通过；`npm run media:check`：唐寅、西方扩充及本批吴道子资源均通过；`npm run build`：类型检查与生产构建通过。浏览器实测唐代目录、两处馆点、两卷详情和完整画幅加载；分别放大至约246%和182%，高清瓦片正常显示。
