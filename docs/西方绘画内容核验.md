# 西方绘画内容核验

核验日期：2026-11-01；蒙德里安增补核验：2026-11-02。项目版本：4.1.1。

本批增加33位画家、134幅作品，覆盖13世纪末至1935年。29位画家各4幅，杜乔、格里斯各3幅，莫奈、梵高各6幅。接入后全站172幅作品、189张图像、40个收藏地点，其中本批新增22个地点。时期／风格是用于浏览的编辑分组，允许年代交叠；画家只在一个主目录出现，作品与收藏关系通过稳定ID连接。

上述为11月1日首批统计。11月2日补入蒙德里安3幅后，本西方专题为33位画家、137幅作品，年代延伸至1944年；蒙德里安从4幅增至7幅。连同独立导入的中国绘画，全站当前为215条作品、459张图像、52个收藏地点。本次新增苏黎世美术馆一处地点。

新增图像：苏黎世美术馆B217馆方复制图1幅、Commons图像2幅。B217以馆方藏品号1987/0028和RKD全集编号核对，排除网上常混用的B219私人收藏版本；未把馆方复制图标成CC0。《百老汇爵士乐》Commons文件说明页提供PD-US-no-notice依据；《胜利爵士乐》API虽标为Public domain，文件页同时保留美国版权恢复提示，因此来源和衍生图均记录`review-required`。既有全部已核验素材的状态不变。

## 来源与核验方式

- 作品标题、作者、年代、媒材和收藏机构主要依据馆方作品记录、馆方公开API或专题资料；每幅记录自己的来源URL。
- 图像逐文件选择：大都会开放图像28幅，芝加哥艺术博物馆开放图像38幅，克利夫兰艺术博物馆开放图像1幅，Wikimedia Commons图像69幅，苏黎世美术馆公版绘画复制图1幅。Commons中《胜利爵士乐》保留待核验状态。
- 大都会、芝加哥的图像要求API公开领域标识为true；克利夫兰要求CC0。Commons要求文件元数据提供Public domain和Copyrighted=False，并核对PD许可模板；《犹太新娘》《戴帽子的女人》的API模板字段不完整，另记录人工复核文件说明页的原属国与美国公版依据。检索结果中的同名摹本、工作室作品、局部、私人收藏版本不直接视为目标原作。
- 图像来源与作品资料来源分别记录。例如格里斯的馆方记录用于核实作品信息，图像采用Commons已标为公版的复制品；不把馆方所有在线图片统称为CC0。
- 中文作品说明为本项目编写的简短视觉导览，不复制馆方长篇介绍。
- 坐标记录机构或建筑的位置，坐标出处另存coordinateSourceUrl；馆藏归属不代表实时展出。冬宫与总参谋部大楼、梵蒂冈绘画馆与拉斐尔画室、泰特不列颠与泰特现代分别设置地点。

开放政策：[大都会](https://www.metmuseum.org/hubs/open-access)、[芝加哥艺术博物馆](https://www.artic.edu/open-access/open-access-images)、[克利夫兰](https://www.clevelandart.org/open-access)。Commons依据每一文件的说明页，见下方选目表。

## 容易混淆的作品与版本

- 本次补齐提香4幅。《圣母升天》为威尼斯弗拉里大殿1516—1518年原作，非维罗纳同题画；《劫夺欧罗巴》为加德纳P26e1原作，非普拉多的鲁本斯摹本。提香生年沿用乌菲齐的1488/1490不确定标注。
- 杜乔《庄严圣母》只收现存正面主画板，排除将散落画板拼合的推测复原图。杜乔卒年各馆标注不同，画家资料保留“1318或1319”。
- 拉斐尔《科隆纳祭坛画》为大都会主体画板；《雅典学院》是原址壁画，定位拉斐尔画室。
- 大卫《荷拉斯兄弟之誓》采用卢浮宫原作图像，排除吉罗代摹本；署年1784、实际1785完成，按馆方记录保留两年。
- 安格尔《灰调宫女》明确标注“安格尔及其工作室”；与卢浮宫1814年《大宫女》分别记录。
- 戈雅两幅1808年事件题材均绘于1814年；《农神吞噬其子》按普拉多现行记录为1820—1823年、壁画转移至画布。
- 透纳《议会大厦失火》为克利夫兰1835年版本，描绘1834年火灾。
- 维米尔《戴珍珠耳环的少女》为毛里茨编号670，蒙克《呐喊》为挪威国家博物馆1893年NG.M.00939。
- 梵高《向日葵》为伦敦1888年版，《阿尔勒的卧室》为芝加哥1889年版；不与阿姆斯特丹、巴黎的同题版本混用。
- 雷诺阿《煎饼磨坊的舞会》为奥赛大幅版本；《富尔奈斯餐厅的午餐》不是菲利普斯收藏馆《游船上的午餐》。
- 马蒂斯《舞蹈》为艾尔米塔什1910年版，非MoMA1909年习作。
- 《巴勃罗·毕加索肖像》作者是胡安·格里斯；《百叶窗》记录泰特馆藏，旧图像文件名中的NG编号不用于定位。
- 克里姆特《吻》《阿特湖畔卡默城堡三号》采用美景宫现行年代标注，保留与旧资料差异的说明。

## 维护与发布

数据入口为content/foreign-catalog.json，下载依据为content/foreign-sources.json，图片清单为content/foreign-media-manifest.json。前端catalog.json由构建脚本合并生成。

```sh
npm run media:foreign -- '/已有下载缓存目录'
npm run content:build
npm test
npm run media:check
PAGES_BASE_PATH=/where-is-art/ npm run build
```

媒体校验离线检查全部402个衍生文件的大小、SHA-256、完整解码、尺寸上限以及来源证据，CI无需访问图片提供方。新下载若与来源清单的哈希不同会停止，需人工重新核实后更新清单。页面按既有Hash路由部署到GitHub Pages。

本轮浏览器核验覆盖桌面、窄屏手机目录、画家范围、收藏地点展开、整图查看与信息浮层；不等同于iOS/Android真机内存性能测试。
