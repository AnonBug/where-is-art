## 重建与验证

网页资源已入库，无需原件即可测试和部署。重建可传入前期研究资料根目录：

```sh
npm run media:tang-expansion -- "/研究资料/tang-top3-20261101"
npm run content:build
npm test
npm run media:check
npm run build
```

不传路径时缓存位于忽略目录 `output/tang-expansion-originals`，缺失原件会按来源清单下载；SHA-256不一致时停止。校验脚本检查全部文件哈希、解码、像素尺寸，以及DZI全部层级和边缘瓦片。

本批网页媒体共 384,945,116 字节（384.95 MB），其中11张图采用DZI，共1,012张瓦片。原始下载文件合计484.80 MB，另行保留。
