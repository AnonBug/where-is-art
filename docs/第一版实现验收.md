# 第一版实现与验收记录

日期：2026-10-31。基线：需求稿 V1.1、图像资源评估与已确认的 MapLibre 选型。

> 底图复核后已改成按视野切换的双源方案：世界概览、中国及周边视野使用天地图，完整海外近景使用 OpenFreeMap。浏览器端 Key 已验证可用。下面的测试记录不代表正式地图内容审核通过。

## 已实现

- React、TypeScript、Vite、Sass Modules；目录、地图、作品信息、看画、数据契约及会话状态分模块。
- 原始 Logo 的 SHA-256 与交接包一致：`d4b33ac1dd03ec392b7bcd1e7f4b6dbd3d101bfc1a0c5ab54caa9d49c1af8c55`。
- MapLibre 按整个视野切换天地图 WMTS 与 OpenFreeMap；海外矢量底图与页面共用青绿配色 token。中国相关视野保留官方成图，南海断续线可见。
- 中国／外国／专题；唐寅 17 幅与达·芬奇相关 21 幅，18 个馆藏机构。专题与聚合计数按唯一作品 ID 计算。
- 桌面目录 + 地图 + 临时详情浮层；手机目录、地图、看画分别全屏；横屏维持单一场景。
- 地图与看画共用作品信息浮层。看画背景保持可见，打开信息不重建画布；仅地图中的信息提供“放大欣赏”。点击、拖动或滚轮操作底层地图／画布会收起信息，同一次操作继续生效；浮层内部交互不关闭。手机竖屏使用底部浮层，横屏使用右侧浮层。
- 地图单独馆点立即显示代表作缩略图；馆名与圆点点击后居中至 9 级城市视图并展开当前范围全部作品，不再打开馆藏列表。手动放大至 9 级及以上也自动展开未聚合馆点，缩小至 8 级及以下收起，中间区间保持原状态。圆点中心对准经纬度；专题作品行定位；地图缩略图打开详情或手机看画；底部作品计数可进入当前作品列表，未知收藏地的作品也可访问。
- HashRouter 深链接、浏览器后退、列表滚动与地图／看画会话位置恢复。
- OpenSeadragon 普通图和 DZI；完整比例、缩放、拖动、还原、高清局部切换、加载失败与重试。
- GitHub 检查工作流及手动 Pages 部署工作流，支持仓库子路径。

## 2026-10-31 双源底图联调

- 最初服务器端 Key 在 Node 探测返回 200，在浏览器被明确拒绝（403 / 301013）。更换浏览器端 Key 后，网页直连成功；Key 未写入源码或报告。
- 天地图 `vec_w` / `ibo_w` / `cva_w` 返回 256 px PNG，支持跨域；实际核看南海约 4.3 级、藏南约 5.9 级及北京约 13 级。南海断续线及官方境界图层可见。
- 巴黎、伦敦抽样的天地图 `vec_w` 在 11、12、14 级返回 200 但内容为 103 字节纯色 PNG，说明不能只凭 HTTP 成功判断海外细节可用。北京对应级别有实际内容。
- 按用户要求实现分视野方案：全球/中国相关视野使用天地图，完全离开保守范围的海外近景使用 OpenFreeMap。巴黎 13.2 级街道显示正常，返回南海后立即切回天地图；实际应用中“蒙娜丽莎 → 卢浮宫定位”显示青绿街道与作品标记。
- 390 × 844 手机尺寸下，“蒙娜丽莎 → 卢浮宫”同样切换到 OpenFreeMap 并显示街道、缩略图及署名；测试后已恢复浏览器默认尺寸。
- 整张样式替换，保留相机和 DOM 馆藏标记；移动、缩放、视口变化均重判。晚到的海外样式不会覆盖已返回中国的视野，销毁后不更新地图。
- 截图保存在 `outputs/art-atlas-implementation/tianditu/`（工作区根目录）；包含官方南海、藏南、北京，以及巴黎的空白原始服务和修复后的双源效果。
- 地图正式审核信息、全范围逐级检查、目标网络和真机测试仍待完成；当前保护框是工程切换范围，部分邻近地区仍保守使用天地图，不代表行政区域划分。

## 2026-11-01 信息浮层自动收起

- 地图和看画在按下画布或滚轮操作时收起信息；事件继续交给 MapLibre／OpenSeadragon，同一次拖动即可平移。浮层文字、链接和内部滚动不会触发关闭。
- 桌面 1280 × 800：事茗图卷在 182% 缩放下直接从信息浮层状态拖动，信息关闭且画作完成平移，缩放保持 182%；故宫地图同样完成拖动，没有历史视野恢复引起的回跳。
- 手机尺寸 390 × 844：分别验证地图与画作，从底部信息浮层打开的状态直接拖动，浮层关闭且画面继续平移。此为桌面浏览器尺寸模拟，尚未做触屏真机验证。
- 自动关闭不把键盘焦点拉回按钮，不添加额外浏览历史；显式关闭看画信息时仍将焦点返回信息按钮。作品、高清局部及馆点参数保留。
- 生产构建与 47 个测试通过；新增桌面／手机地图与看画的首个手势、浮层内部操作、返回路径回归检查。截图位于工作区 `outputs/art-atlas-implementation/info-dismiss/`。

## 已修复的联调问题

1. StrictMode 初次清理误存默认相机，导致世界范围没有覆盖全部收藏点：只在地图初始化后记录相机。
2. 返回地图时重复消费旧定位指令：定位成功即清除指令，优先恢复历史位置。
3. OpenSeadragon 6 默认 WebGL drawer 不触发旧的 `tile-drawn`：改用跨 drawer 的 `tile-loaded`，消除已显示图像仍报超时的提示。
4. 放大时预览图可能透出：首张图块加载后隐藏预览层。
5. 切换中国／外国目录仍沿用上一分类范围：切换时同步范围。
